## Usage

```tsx

```

```tsx
<Typewriter
  text={[
    "Building pixels with purpose",
    "Shipping faster than deadlines",
    "Deploy now, panic later!",
    "...",
  ]}
/>
```

## Props

| Prop                  | Type       | Default | Description                                |
| --------------------- | ---------- | ------- | ------------------------------------------ |
| `text`                | `string[]` | -       | Array of strings to display                |
| `letterDelay`         | `number`   | `0.025` | Delay between each letter (in seconds)     |
| `boxFadeDuration`     | `number`   | `0.125` | Duration of the box fade (in seconds)      |
| `textFadeOutDuration` | `number`   | `0.25`  | Duration of the text fade out (in seconds) |
| `delayBetween`        | `number`   | `5500`  | Delay between each text fade out (in ms)   |
| `className`           | `string`   | -       | Optional class names for custom styling.   |
