## Usage

```tsx
import { MagneticHover } from "@/components/magnetic-hover";
```

```tsx {1,3}
<MagneticHover>
  {/* Pass any children here, and the magnetic effect will be applied to it.*/}
</MagneticHover>
```

## Props

| Prop       | Type              | Default | Description                                         |
| ---------- | ----------------- | ------- | --------------------------------------------------- |
| `children` | `React.ReactNode` | -       | The content to which the magnetic effect is applied |
| `strength` | `number`          | `1`     | Controls the intensity of the magnetic effect       |
